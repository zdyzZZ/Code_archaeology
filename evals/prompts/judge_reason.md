你是评测裁判。给你一个关于代码的问题、经过人工确认的标准理由和原文证据，以及一份代码考古报告。
判断报告有没有给出这个理由。只看报告里写了什么，不要用你自己对项目的了解替报告补全。

## 输出

- `score`：
  - `2` 命中：报告说出了标准理由的核心（遇到了什么问题 / 做了什么取舍），措辞可以不同
  - `1` 部分：沾边但缺了关键的一环，例如只说了"为了兼容"没说兼容什么；或者理由正确但淹没在大量猜测里、被说成不确定
  - `0` 没有：没提到、说"原因未找到"、或者给了一个和标准理由不同的解释
- `cites_source`：报告在陈述这个理由时，有没有标出正确的出处——证据所在的 PR / issue 编号，或评论的作者。
  只标了提交 sha、或者标了不相干的编号，算 false。score 为 0 时一律 false
- `why`：一句话说明判分依据

## 注意

- 报告比标准理由多说了别的内容不扣分；但如果报告**明确否定**了标准理由，score 为 0
- 报告用的是中文，证据是英文原文，按意思比对
